Le filtre ne s'affiche pas
============================

Un filtre souhaité ne s'affiche pas sur le site.

Checklist :

   |box| la règle de filtre a été créée

   |box| la règle de filtre est activée

   |box| dans le CE/module FE, le jeu de filtres correspondant est sélectionné (réglages de filtrage à appliquer)

   |box| dans le CE/module FE, la règle de filtre est activée (attributs) - en cas de modification de la règle de filtre, celle-ci doit éventuellement être réactivée

   |box| le CE/module FE est réglé sur actif/visible
