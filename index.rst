Bienvenue sur MetaModels !
============================

Ceci est la documentation officielle de `MetaModels <https://now.metamodel.me>`_, une extension
pour le `système de gestion de contenu Contao <https://contao.org>`_. Avec l'extension MetaModels, il
est possible de stocker des données structurées dans le CMS Contao et de les afficher sur le site web - pour en
savoir plus sur la structure et l'utilisation, voir :ref:`introdution_was-ist-metamodels`. L'abréviation
courante de MetaModels est « MM ».


Cette documentation se divise en trois parties :

    :ref:`index_manual` - Ici est documenté tout ce qui concerne MetaModels de manière générale.

    :ref:`index_cookbook` - Workflows et exemples de « bonnes pratiques » pour travailler avec MetaModels.

    :ref:`index_reference` - Documentation sur les événements, les interfaces et bien plus encore.


Soutien et dons
-----------------
L'extension MetaModels est une extension gratuite basée sur l'open source et nécessite, pour son
développement continu, le soutien d'une communauté active. Les contributions sous forme de
programmation ou de signalement de bugs, ainsi que le partage de vos propres workflows, sont les bienvenus.
Des informations sont disponibles sur la `page du projet MetaModels <https://now.metamodel.me>`_, sur `Github
<https://github.com/MetaModels>`_ ou sur le `forum Contao <https://community.contao.org/de/forumdisplay.php?149-MetaModels>`_.

Les contributions financières sous forme de dons sont également importantes pour le développement continu et
la maintenance du projet. Plus d'informations sur la `page de dons de MetaModels <https://now.metamodel.me/de/unterstuetzer/spenden>`_
